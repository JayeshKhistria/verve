# Verve Cleaning Website

A five-page responsive commercial cleaning website built with plain HTML, CSS, and JavaScript.

## Pages
- `index.html`
- `about.html`
- `services.html`
- `service-areas.html`
- `contact.html`

## Run locally
Open `index.html` directly in a browser, or use a local server such as VS Code Live Server.

## Customize
1. Replace the business name, phone number, email, and service area.
2. Replace placeholder SVGs and placeholder blocks with real images.
3. Update service descriptions and city coverage.
4. Connect the contact form to Formspree, Web3Forms, EmailJS, Netlify Forms, PHP, or a custom backend.
5. Add your real privacy policy and terms pages.
6. Replace sample testimonials with verified customer feedback.

## Hero video
A commented video block is available in `index.html`. Add an MP4 to `assets/videos/` and uncomment the markup.

## Deployment
This static website can be hosted on:
- Netlify
- Vercel
- GitHub Pages
- Cloudflare Pages
- Any standard cPanel web host


## Global editable settings
Edit `js/config.js` to change the company name, initials, phone, email, address, business hours, CTA labels, service-area list, and social links.

## Color controls
Edit the variables at the top of `css/style.css`:
- `--primary` and `--primary-dark`: calm blue-gray brand colors
- `--accent` and `--accent-dark`: red CTA and button colors
- `--light`, `--text`, `--muted`, and `--border`: supporting neutral colors
